# Servicio Usuarios

Se encarga de la lógica de gestión de los usuarios:

Las competencias de este servicio tienen que estar relacionadas con la autenticación.
- Crea usuarios
- Autentica usuarios
- Devuelve el JWT correspondiente cuando valide el usuario
- Elimina usuarios (desactiva)

Los métodos de JWT se encuentran dentro de la carpeta **`../utils`**
